2.2 安装流程步步通

安装过程看似简单，但有几个关键点需要注意：

  1. 下载完成后，首次打开应用时，iOS系统会提示"未受信任的企业级开发者"。这时需要进入"设置"→"通用"→"设备管理"，找到对应的开发者证书并选择信任。

  2. 授予小火箭必要的网络权限。在iOS的"设置"→"无线局域网"中，确保小火箭的应用权限设置为"无线局域网与蜂窝数据"。

  3. 建议将小火箭添加到控制中心，方便快速启用和切换。这可以在"设置"→"控制中心"→"自定控制"中完成。

当小火箭无法正常工作时，可以按照以下步骤排查：

  2. 验证订阅状态：在"配置"页面查看订阅是否过期，必要时联系服务商续费或更新。

  3. 更换节点尝试：有时特定节点可能出现临时故障，切换到其他节点往往能解决问题。

  4. 检查本地时间：错误的系统时间会导致SSL证书验证失败，确保设备时间与所在时区一致。

FAQ

VLESS 是否比 Trojan 更稳定？
两者都非常稳定，但 VLESS 在多平台兼容性上略优，而 Trojan 在 HTTPS 伪装和 TLS 安全性上更强。选择取决于服务器环境与具体需求，两者皆为高性能协议。
WinXray 的测速功能不显示结果怎么办？
测速依赖于节点响应时间与服务器网络质量。若测速为空白，请检查系统时间同步、网络防火墙及代理端口设置是否正确；也可更新到最新版本修复已知测速模块异常问题。
VLESS + XTLS 如何降低移动网络延迟？
XTLS 通过减少握手次数和加密开销降低延迟。结合策略组和多节点切换，可在高延迟或不稳定的移动网络环境中保持连接稳定，提升网页浏览、视频和游戏体验流畅度。
Sing-box 能否直接读取 Clash 配置？
Sing-box 原生支持 Clash YAML 格式的导入，会自动解析成自身 JSON 结构。虽然部分脚本功能不兼容，但节点和规则可以正常使用，迁移过程非常平滑。
Nekoray 的订阅更新支持自动导入节点吗？
支持。Nekoray 可以通过订阅 URL 自动下载节点，并根据用户配置更新本地节点列表。定期更新确保节点始终可用，减少手动维护的麻烦，提高使用便利性。
何为 multiplex (mux)，启用后会有哪些利弊？
mux 是多路复用技术，可在单一连接上传输多路流量，从而减少握手次数与连接开销。优点是提升短连接并发效率，缺点是在丢包或单连接异常时可能影响多条会话并增加调试复杂度。
Hysteria2 的多路复用如何提高传输效率？
Hysteria2 利用 QUIC 的多路复用功能，将多个请求共享单个 UDP 连接，减少握手次数和延迟，提升整体吞吐量。尤其在高并发场景中效果显著。
Hysteria2 的多路复用在短连接场景下有什么优势？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适合高频短连接应用，如游戏和即时通讯，能提高吞吐量和连接稳定性，优化网络体验。
WinXray 是否支持多订阅源？
支持。用户可导入多个订阅 URL，每个订阅源独立管理。通过切换订阅源或合并策略组，可灵活管理节点，实现不同地区或用途的线路分配。
Netch 如何实现 UDP 游戏加速？
Netch 支持 UDP 转发，可专门为游戏流量建立高速通道。结合策略组和节点延迟检测，可有效减少丢包和延迟，提高游戏体验的流畅性和稳定性。
